# Documentación de Festeka

Festeka es el directorio y buscador de proveedores de eventos de Valledupar (y luego del Caribe). Su producto central es **Arma tu evento**: el cliente describe su fiesta, la plataforma le sugiere proveedores por categoría y él elige con quién cotizar.
